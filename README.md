## Требования
*   Python 3.9+
*   pip

## Как запустить
1. Клонируйте репозиторий:
    git clone https://github.com/drachevvv23-sys/-ML.git
    cd -ML.git
2. Создание виртуального окружения
    python -m venv venv
    venv\Scripts\activate
3. Установите зависимости:
    pip install -r requirements.txt
4. Запуск Jupyter Notebook 
    pip install jupyter
    jupyter notebook
3. Запустите проект:
    В открывшемся окне браузера нажмите на файл Курсовая.ipynb
